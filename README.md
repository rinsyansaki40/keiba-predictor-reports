# keiba-predictor-reports

競馬予測レポート(HTML)の公開専用リポジトリ。

`keiba-predictor-live` の週次自動実行から、予測結果のHTMLレポートが
`reports/<race_date>.html` として自動でpushされます。予測モデル・
スクレイピングコード等は含みません(それらは非公開の `keiba-predictor-live` /
`keiba_predictor_deep_4` 側で管理)。

公開URL: https://rinsyansaki40.github.io/keiba-predictor-reports/reports/<race_date>.html
